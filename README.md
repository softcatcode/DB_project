# Проект PostgreSQL — Страны и футболисты

## Описание проекта

Консольное приложение на Python для работы с базой данных PostgreSQL. Проект предназначен для хранения информации о странах и футболистах, а также для управления связанными записями.

Приложение использует две таблицы:
- `country` — информация о странах;
- `player` — информация о футболистах.

Связь между таблицами осуществляется через внешний ключ `country_id`.

## Структура проекта

```text
DB_project/
```

## Используемые технологии

- Python 3
- PostgreSQL
- psycopg2 — взаимодействие с PostgreSQL
- PyYAML — чтение конфигурационного файла
- BeautifulTable — отображение данных в виде таблиц в консоли

## Настройка проекта

### 1. Подготовка базы данных

Установите PostgreSQL и убедитесь, что сервер базы данных запущен.

Создайте базу данных или используйте существующую.

### 2. Настройка подключения

Откройте файл `config.yaml` и укажите параметры подключения к PostgreSQL:

```yaml
dbname: postgres
user: postgres
password: your_password
host: localhost
dbtableprefix: "public."
```

Где:
- `dbname` — название базы данных;
- `user` — имя пользователя PostgreSQL;
- `password` — пароль пользователя;
- `host` — адрес сервера PostgreSQL;
- `dbtableprefix` — схема и префикс таблиц.

При необходимости замените значения на соответствующие параметрам вашей базы данных.

### 3. Установка библиотек

Откройте терминал в корневой папке проекта и выполните команду:

```bash
pip install psycopg2-binary PyYAML beautifultable
```

## Запуск приложения

Для запуска программы выполните команду:

```bash
python main.py
```

При первом запуске необходимо перейти в главное меню и выбрать пункт:

**2 — сброс и создание таблиц.**

После подтверждения будут созданы таблицы `country` и `player`.

**Внимание!** Сброс удаляет существующие таблицы вместе со всеми находящимися в них данными.

## Функциональные возможности

### Работа с футболистами

В меню футболистов доступны следующие операции:

1. Добавление нового футболиста.
2. Изменение информации о футболисте.
3. Удаление футболиста.
4. Просмотр всех футболистов.
5. Просмотр футболистов выбранной страны.

При добавлении и редактировании футболиста можно указать имя, фамилию, дату рождения и страну.

### Работа со странами

В меню стран доступны следующие операции:

1. Просмотр списка стран.
2. Добавление новой страны.
3. Изменение информации о стране.
4. Удаление страны вместе со связанными футболистами.

Для каждой страны хранятся краткое название, полное название и регион.

### Проверка вводимых данных

В приложении предусмотрены проверки:
- обязательности заполнения полей;
- максимальной длины строк;
- корректности формата даты рождения;
- запрета указания даты рождения в будущем;
- выбора региона из установленного списка;
- выбора существующей страны;
- корректности номеров записей.

Для отмены ввода данных предусмотрено значение `0` в соответствующих полях.

## Особенности реализации

- Для работы с базой данных используется библиотека `psycopg2`.
- Для безопасной подстановки пользовательских значений используются параметризованные SQL-запросы.
- Для формирования SQL-запросов с именами таблиц и столбцов применяется `psycopg2.sql`.
- Первичные ключи используются внутри программы и не запрашиваются у пользователя.
- Для выбора и удаления записей используются порядковые номера из отображаемых списков.
- При удалении страны сначала удаляются связанные с ней футболисты.
- Для хранения данных используются классы `Country` и `Player`, реализованные с помощью `dataclass`.

## Структура базы данных

### Таблица country

| Поле | Тип данных | Описание |
|---|---|---|
| country_id | SERIAL | Первичный ключ |
| short_name | VARCHAR(100) | Краткое название |
| full_name | VARCHAR(200) | Полное название |
| region | VARCHAR(50) | Регион |

### Таблица player

| Поле | Тип данных | Описание |
|---|---|---|
| player_id | SERIAL | Первичный ключ |
| last_name | VARCHAR(100) | Фамилия |
| first_name | VARCHAR(100) | Имя |
| birth_date | DATE | Дата рождения |
| country_id | INTEGER | Внешний ключ страны |

Для таблицы `country` предусмотрена уникальность краткого и полного названий, а также ограничение на допустимые регионы.

Для таблицы `player` предусмотрено ограничение, запрещающее дату рождения в будущем, и внешний ключ для связи со страной.
